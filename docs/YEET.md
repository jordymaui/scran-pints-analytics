# YEET reporting

The combined view adds available Scran & Pints reporting from YouTube, Instagram and TikTok. Its source list shows which accounts contribute data. An unconnected account is unavailable and contributes no invented values.

Instagram currently contributes a reviewed native browser capture held in private hosted storage. The runtime reporting endpoint publishes selected validated fields; the capture is excluded from GitHub and the static build. The default combined headline is **Reported views**, adding each platform's available native reporting history once. It combines YouTube/TikTok daily history with Instagram's widest captured 90-day report. It is not a lifetime total or a single shared date window. The source bars show the separate coverage; recorded actions retain each platform's definition. Current account follows include the captured Instagram follower stock. Public lifetime counters remain a separately scoped secondary measure.

Instagram's captured 7/30/90-day reports overlap and are never added together. They have relative native labels but no observed exact boundaries or timezone, so they remain separate from aligned daily graphs and growth calculations. The Instagram detail page includes all reviewed account windows, native breakdowns, profile activity, Monday follower activity and an explicitly labelled inspected Reel sample. Its complete Reel inventory, daily history and demographics are unavailable. Public Refresh keeps the dated capture until a newer reviewed capture is published.

- YouTube includes all channel formats. The separately reported Shorts source is a subset and is never added a second time.
- All-time headline counters use the latest saved public channel or returned-content lifetime counters. They retain their source capture dates. Followers across accounts are follows, not unique people.
- The performance graph uses native daily reporting. Its available history and processed end dates can differ from current public counters. A graph of saved history is not reconstructed from lifetime totals. The 7-day and 30-day views end on the latest common processed date for the participating native sources. All-time graphing retains the union of their available history through the latest source end date.
- Period comparisons use equal calendar windows. A growth percentage requires complete numeric data in both windows for the same participating sources; missing rows do not become zeroes. Each platform's graph keeps missing values as gaps. A strict combined daily value is unavailable when a participating platform is missing that day. Separately labelled reported totals and their cumulative line add only the native values actually available, with incomplete coverage identified. These reported-history totals can differ from the all-time public-counter headline. Platform calendar days retain their native or unspecified timezones.
- Cross-platform views are added counts under each platform's definition. They are not deduplicated reach, sponsor impressions or conversions.
- Native engagement totals and the interaction breakdown use the same complete platform-day reports for likes, comments and shares. An incomplete platform-day remains unavailable rather than contributing a partial interaction total. Other complete platform-days remain included, with growth withheld whenever coverage is incomplete.
- Native audience percentages retain their platform, population and reporting window. They do not establish a shared absolute denominator or a combined unique audience. Country charts show platform results side by side.
- The separately labelled channel average describes the available platforms' audience profiles with equal weight per platform. It is not weighted by views, followers or audience size. Gender uses the native viewer profiles. Age first conditions each platform's available profile on ages 18 and above, combines older bands into 55+, then averages the same adult bands across platforms. Reported under-18 YouTube viewers are explicitly excluded from that adult comparison, not changed to zero. Native platform tabs retain their original categories and values. Sources can cover different reporting windows, shown alongside the comparison.
- TikTok Studio imports retain their own dates. Daily viewer counts are not summed into a period unique-viewer total. Follower stocks and separately exported net changes remain distinct. Censored percentages such as `<1%` retain that threshold.

Refresh collects connected API reports. It does not update manually imported TikTok Studio evidence. Connection management and importing shared evidence require an approved team session.
